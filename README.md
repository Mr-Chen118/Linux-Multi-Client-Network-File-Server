\# Linux-Multi-Client-Network-File-Server



项目简介:
基于 TCP Socket 的多客户端并发文件传输服务器，支持多客户端同时连接、消息广播与文件收发。

主要功能:
- 多客户端同时连接
- pthread 多线程并发处理
- 客户端上传文件
- 客户端下载文件
- 服务端文件管理
- 消息广播
- TCP 数据可靠传输

技术栈:
- C
- Linux/POSIX
- TCP/IP
- Socket
- pthread
- File I/O
- Makefile
- Git

运行环境:
Ubuntu 24.04
GCC
Linux

开发工具:
VScode
